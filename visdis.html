📊 Histogram vs Density Plot vs Boxplot

Histogram

Shows the frequency distribution across intervals.

Boxplot

Shows median, quartiles, spread and potential outliers.

Teaching tip: Ask participants what they can see in each graph before showing the numerical statistics.

💻 ggplot2: Continuous Variable Visualization

library(ggplot2)

# Histogram
ggplot(data, aes(x = Age)) +
  geom_histogram(bins = 20, fill = "steelblue", color = "white") +
  labs(title = "Distribution of Age",
       x = "Age", y = "Frequency") +
  theme_minimal()

# Density plot
ggplot(data, aes(x = Age)) +
  geom_density(fill = "skyblue", alpha = 0.5) +
  labs(title = "Density of Age",
       x = "Age", y = "Density") +
  theme_minimal()

# Boxplot
ggplot(data, aes(y = Age)) +
  geom_boxplot() +
  labs(title = "Boxplot of Age", y = "Age") +
  theme_minimal()

# Violin plot
ggplot(data, aes(x = "", y = Age)) +
  geom_violin(fill = "orchid", alpha = 0.6) +
  geom_boxplot(width = 0.12) +
  labs(title = "Violin + Boxplot of Age", x = NULL, y = "Age") +
  theme_minimal()

📐 Detecting Skewness and Outliers

  • Right-skewed: long tail toward larger values; mean may exceed median.
  • Left-skewed: long tail toward smaller values; mean may be below median.
  • Symmetric: mean and median are often relatively close.
  • Potential outliers: observations unusually far from the main distribution.
# Boxplot statistics
boxplot.stats(data$Age)

# Identify possible boxplot outliers
boxplot(data$Age)$out

# Quantiles
quantile(data$Age, probs = c(.25, .50, .75), na.rm = TRUE)

💻 ggplot2: Categorical Visualization

library(ggplot2)

# Bar chart
ggplot(data, aes(x = Sex)) +
  geom_bar() +
  labs(title = "Participants by Sex",
       x = "Sex", y = "Frequency") +
  theme_minimal()

# Ordered bar chart using counts
ggplot(data, aes(x = reorder(Department, Department, function(x) -length(x)))) +
  geom_bar() +
  coord_flip() +
  labs(title = "Participants by Department",
       x = "Department", y = "Frequency") +
  theme_minimal()

# Proportion chart
ggplot(data, aes(x = Sex, fill = Department)) +
  geom_bar(position = "fill") +
  scale_y_continuous(labels = scales::percent) +
  labs(title = "Department Composition by Sex",
       x = "Sex", y = "Percentage") +
  theme_minimal()

⚠️ Common Mistakes with Categorical Variables

Do not:
Calculate a mean of arbitrary category codes such as 1 = Male and 2 = Female.
Do not:
Ignore the denominator when reporting percentages.
Do:
Report n and % together whenever useful.
Do:
Preserve the meaningful order of ordinal categories.

🔎 4. Exploring Continuous Variables by Groups

🔬 Example research question: Does age have a different distribution across departments?
library(ggplot2)

# Boxplot by group
ggplot(data, aes(x = Department, y = Age)) +
  geom_boxplot() +
  labs(title = "Age Distribution by Department",
       x = "Department", y = "Age") +
  theme_minimal()

# Violin + boxplot
ggplot(data, aes(x = Department, y = Age, fill = Department)) +
  geom_violin(alpha = 0.5) +
  geom_boxplot(width = 0.12) +
  theme_minimal()

# Histogram by group
ggplot(data, aes(x = Age)) +
  geom_histogram(bins = 20) +
  facet_wrap(~ Department) +
  theme_minimal()
Interpretation: Compare centre, spread, skewness and unusual observations across groups. Visualization is exploratory; it does not by itself establish statistical significance.

📋 Descriptive Summary by Group

# Base R
aggregate(Age ~ Department, data = data,
          FUN = function(x) c(
            mean = mean(x, na.rm = TRUE),
            median = median(x, na.rm = TRUE),
            sd = sd(x, na.rm = TRUE)
          ))

# dplyr approach
library(dplyr)

data %>%
  group_by(Department) %>%
  summarise(
    n = sum(!is.na(Age)),
    mean = mean(Age, na.rm = TRUE),
    median = median(Age, na.rm = TRUE),
    sd = sd(Age, na.rm = TRUE),
    IQR = IQR(Age, na.rm = TRUE)
  )

🧠 Quick Decision Tree

Step 1

Is the variable numerical?

↓ Yes → Examine distribution.

Step 2

Is it categorical?

↓ Yes → Use frequency and percentage.

Step 3

Numerical distribution?

Symmetric → mean/SD; skewed → median/IQR.

Step 4

Need a visual?

Continuous → histogram/boxplot; categorical → bar chart.

🎯 Test Yourself

Click an option to reveal the explanation.

Scenario 1

Age is strongly right-skewed. Which summary is generally more representative of the centre?

Answer: Median with IQR.
The median is less sensitive to extreme values than the mean.

Scenario 2

Sex is coded 1 = Male and 2 = Female. What should you report?

Answer: Frequency and percentage.
The numbers are category codes, not measurements.

Scenario 3

Which graph is especially useful for showing the distribution of a continuous variable?

Answer: Histogram.
A histogram displays the distribution of numerical observations across intervals.

Scenario 4

You want to compare the distribution of a continuous outcome across four departments. Which plot is particularly useful?

Answer: Boxplot.
It allows comparison of centre, spread and potential outliers across groups.

Scenario 5

Which R function produces a frequency table for a categorical variable?

Answer: table().
For example: table(data$Sex).

💻 Complete R Laboratory

This script gives participants one reproducible workflow from importing data to descriptive reporting.

# =========================================================
# DATA VISUALIZATION & DESCRIPTIVE STATISTICS USING R
# =========================================================

# 1. Install packages once if necessary
# install.packages(c("tidyverse", "scales"))

library(tidyverse)
library(scales)

# 2. Import data
data <- read.csv("mydata.csv")

# 3. Inspect
head(data)
str(data)
summary(data)
dim(data)
colSums(is.na(data))

# ---------------------------------------------------------
# 4. CATEGORICAL VARIABLES
# ---------------------------------------------------------

# Frequency
table(data$Sex)

# Percentage
round(prop.table(table(data$Sex)) * 100, 1)

# Bar chart
ggplot(data, aes(x = Sex)) +
  geom_bar() +
  labs(title = "Distribution of Sex",
       x = "Sex", y = "Frequency") +
  theme_minimal()

# ---------------------------------------------------------
# 5. CONTINUOUS VARIABLES
# ---------------------------------------------------------

# Descriptive statistics
mean(data$Age, na.rm = TRUE)
median(data$Age, na.rm = TRUE)
sd(data$Age, na.rm = TRUE)
IQR(data$Age, na.rm = TRUE)
quantile(data$Age, na.rm = TRUE)

# Histogram
ggplot(data, aes(x = Age)) +
  geom_histogram(bins = 20) +
  labs(title = "Distribution of Age",
       x = "Age", y = "Frequency") +
  theme_minimal()

# Density plot
ggplot(data, aes(x = Age)) +
  geom_density(fill = "steelblue", alpha = .4) +
  labs(title = "Density Plot of Age",
       x = "Age", y = "Density") +
  theme_minimal()

# Boxplot
ggplot(data, aes(y = Age)) +
  geom_boxplot() +
  labs(title = "Boxplot of Age", y = "Age") +
  theme_minimal()

# ---------------------------------------------------------
# 6. CONTINUOUS VARIABLE BY CATEGORY
# ---------------------------------------------------------

ggplot(data, aes(x = Sex, y = Age)) +
  geom_boxplot() +
  labs(title = "Age Distribution by Sex",
       x = "Sex", y = "Age") +
  theme_minimal()

# ---------------------------------------------------------
# 7. TWO CATEGORICAL VARIABLES
# ---------------------------------------------------------

tab <- table(data$Sex, data$Department)
tab

# Row percentages
round(prop.table(tab, 1) * 100, 1)

# Proportional bar chart
ggplot(data, aes(x = Sex, fill = Department)) +
  geom_bar(position = "fill") +
  scale_y_continuous(labels = percent) +
  labs(title = "Department Composition by Sex",
       x = "Sex", y = "Percentage") +
  theme_minimal()

# ---------------------------------------------------------
# 8. GROUPED DESCRIPTIVE STATISTICS
# ---------------------------------------------------------

data %>%
  group_by(Sex) %>%
  summarise(
    n = sum(!is.na(Age)),
    mean_age = mean(Age, na.rm = TRUE),
    median_age = median(Age, na.rm = TRUE),
    sd_age = sd(Age, na.rm = TRUE),
    IQR_age = IQR(Age, na.rm = TRUE)
  )

# ---------------------------------------------------------
# 9. SAVE A GRAPH
# ---------------------------------------------------------

p <- ggplot(data, aes(x = Age)) +
  geom_histogram(bins = 20) +
  theme_minimal()

ggsave("age_histogram.png", p, width = 7, height = 5, dpi = 300)

📝 Research Reporting Templates

Continuous variable:
“The median age was XX years (IQR: XX–XX years). The distribution was right-skewed, with several higher observations.”
Approximately symmetric continuous variable:
“The mean age was XX years (SD = XX years).”
Categorical variable:
“Among the participants, XX (XX%) were female and XX (XX%) were male.”
Graph:
“Figure 1 presents the distribution of age. The histogram indicates that the variable is approximately symmetric/right-skewed/left-skewed.”

🏆 Final Checklist

  1. Have I correctly identified every variable type?
  2. Have I checked missing values?
  3. Have I checked unusual or impossible values?
  4. Have I selected mean/SD or median/IQR based on the distribution?
  5. Have I reported n (%) for categorical variables?
  6. Have I selected a graph appropriate to the variable?
  7. Have I labelled axes and categories clearly?
  8. Have I avoided interpreting category codes as numerical measurements?
  9. Have I described what the graph actually shows?
  10. Can another researcher reproduce my analysis from my R code?
Final practice: Obtain data → Inspect → Identify variable types → Calculate descriptive statistics → Visualize → Compare groups → Interpret → Report.
