What is Cluster Analysis?

Cluster Analysis → Group observations so that observations within the same cluster are similar, while observations in different clusters are dissimilar.

Main idea: High within-cluster similarity and low between-cluster similarity. Cluster analysis is an unsupervised learning technique because no outcome variable or predefined group membership is required.

Common steps:

1. Select variables
2. Standardize variables if necessary
3. Choose a distance measure
4. Apply a clustering method
5. Select the number of clusters
6. Evaluate cluster quality
7. Interpret and profile clusters

Why Standardize?

Variables measured on larger scales can dominate distance calculations. Z-score standardization puts variables on a comparable scale:

z = (x − mean) / SD
