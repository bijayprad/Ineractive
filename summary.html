📖 Teaching Notes

Mean: x̄ = Σx / n
Sample variance: s² = Σ(x − x̄)² / (n − 1)
Sample SD: s = √s²
Pearson skewness: Sk = 3(x̄ − Median) / s
Moment skewness: γ₁ = μ₃ / σ³
Excess kurtosis: γ₂ = μ₄ / σ⁴ − 3

Rule of thumb for skewness: near 0 → approximately symmetric; positive → right-skewed; negative → left-skewed.

Kurtosis: excess ≈ 0 → mesokurtic; positive → leptokurtic; negative → platykurtic.
