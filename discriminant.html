What is Discriminant Analysis?

Discriminant Analysis uses one or more quantitative predictor variables to classify observations into predefined groups.

Main objective: Find a linear combination of predictors that maximally separates the known groups and use it to classify new observations.

Basic workflow

1. Define known groups → 2. Select predictors → 3. Estimate group means and covariance → 4. Construct discriminant functions → 5. Classify observations → 6. Evaluate accuracy

Main Assumptions

1. Independent observations
Each observation should be independent.

2. Multivariate normality
Predictors should be approximately multivariate normal within groups.

3. Homogeneity of covariance matrices
LDA assumes similar covariance structures across groups.

4. Limited multicollinearity
Predictors should not be excessively correlated.
